# TMC4671 Class State Machine Documentation

This document describes the operation of the FreeRTOS thread state machine for the `TMC4671` class, responsible for controlling the Trinamic TMC4671 motor driver.

## 1. Possible States

The `TMC_ControlState` enum (`TMC4671.h`) defines the states of the state machine (`CoggingCalibration` is conditionally compiled when `COGGING_TABLE_FLASH_START_ADDRESS` is defined):

| State | Role |
| :--- | :--- |
| `uninitialized` | Initial startup, SPI ping, and base register initialization |
| `waitPower` | Waiting for VM (motor supply voltage) to stabilize and calibrating ADCs |
| `Shutdown` | Motor stopped, `DRV_ENABLE` low, FOC PWM off; monitors E-stop recovery |
| `Running` | Active operational state; periodic 200 ms fault, E-stop, and temperature supervision |
| `EncoderInit` | Internal encoder alignment sequence |
| `ExternalEncoderInit` | External encoder alignment sequence |
| `EncoderFinished` | Encoder aligned; transitions to `SlewRateCalibration` (if full calib), `Running`, or `Shutdown` |
| `HardError` | Fatal latched fault (absorbing state); requires MCU reset |
| `OverTemp` | Thermal protection triggered; immediately latches `HardError` |
| `IndexSearch` | Searching for encoder index pulse (`autohome()`) |
| `FullCalibration` | Complete commissioning routine (ADC offset + encoder calibration + slew-rate) |
| `Pidautotune` | Torque/flux PI current-loop auto-tuning |
| `CoggingCalibration` | Anti-cogging & multi-speed ripple harmonic calibration (`TMC4671CoggingCalibrator`) |
| `SlewRateCalibration` | Maximum current slew-rate measurement (`measureMaxSlewRate()`) |
| `NONE` | Sentinel placeholder for `postPowerState` recovery logic |

## 2. State Control & Safety Variables

- `volatile TMC_ControlState state`: Current active state.
- `TMC_ControlState laststate`: Previous state saved when `newState != state`.
- `volatile TMC_ControlState requestedState`: Next intended state, applied at the top of `Run()` when `allowStateChange` is `true`.
- `TMC_ControlState postPowerState`: Stores a calibration state (`FullCalibration`, `Pidautotune`, `SlewRateCalibration`) to resume automatically after a power loss/recovery cycle.
- `volatile bool allowStateChange`: Lock that prevents `requestedState` from overwriting `state` during critical internal routines or fault states.
- **Safety & readiness flags**: `volatile bool emergency`, `volatile bool estopTriggered`, `volatile bool motorEnabledRequested`, `volatile bool flagCheckPending`, `volatile bool initialized`, `volatile bool powerInitialized`, `volatile bool adcCalibrated`, `volatile bool encoderAligned`, and external `brake_failure` (`voltagesense.h`).

## 3. Transition Mechanism (`changeState`)

`changeState(TMC_ControlState newState, bool force = false)` manages state transitions with strict fault protection:
- **Absorbing `HardError`**: If `state == HardError`, `changeState()` returns immediately and refuses all transitions until MCU reset. Entering `HardError` locks `allowStateChange = false`, `requestedState = HardError`, and `state = HardError`.
- **`force = true`**: Immediately assigns `state = newState`. For privileged boot/power states (`uninitialized`, `waitPower`), it also sets `allowStateChange = false` so a pending `requestedState` cannot overwrite the transition on the next loop tick.
- **`force = false`**: Sets `requestedState = newState`. The transition is applied at the start of the next `Run()` iteration if `allowStateChange` is `true`.
- `laststate` is updated only when `newState != state`.

## 4. Detailed Description of States and Transitions

The state machine runs inside the `TMC4671::Run()` FreeRTOS thread loop (with a `Delay(10)` pacing interval). Before dispatching the `switch(state)`, `Run()` enforces global safety invariants:
1. If `brake_failure` is asserted, it calls `emergencyStop(false)`, logs `BRAKE_RES_ERROR`, and latches `HardError` via `enterHardError()`.
2. If `!initialized` (and not `HardError`), it forces `uninitialized`.
3. If `isEmergencyActive()` (and not `HardError`/`Shutdown`), it calls `enterShutdown()` to immediately cut the power stage.

After the `switch`, `Run()` checks for VM loss (`!hasPower()` -> `disablePowerStage()` + forced `waitPower`) and processes deferred `FLAG_Pin` interrupts (`flagCheckPending` -> `statusCheck()` in thread context with SPI semaphore protection).

> **Blocking vs. Asynchronous Execution**: While the TMC thread runs asynchronously with respect to the main/USB/Axis threads, **calibration routines (`CoggingCalibration`, `Pidautotune`, `FullCalibration`, `SlewRateCalibration`, `IndexSearch`, `EncoderInit`) execute synchronously within `Run()`** with `allowStateChange = false`. All calibration loops continuously check `canRunMotor()`, `isEmergencyActive()`, `brake_failure`, and `hasPower()` so faults abort safely within milliseconds.

---

### **State: `uninitialized`**
- **Role**: Hardware discovery and base setup.
- **Actions**: Locks `allowStateChange = false`, pings the TMC4671 (retrying every 250 ms if unresponsive or `emergency` is set), and calls `initialize()` to configure PWM, motor type, ADC, filters, and status mask.
- **Transition**: Forces `waitPower` on success.

---

### **State: `waitPower`**
- **Role**: Monitors supply voltage (VM) and handles power-on / brownout recovery.
- **Actions**:
  1. Checks `hasPower()`, `!isEmergencyActive()`, and `!brake_failure`.
  2. Special case: allows `CoggingCalibration` in simulation mode without VM if no emergency or brake fault is active.
  3. Once VM is stable for **6 consecutive checks** (`++powerCheckCounter > 5`), calls `initializeWithPower()` (staying in `waitPower` if ADC calibration fails).
  4. If already `powerInitialized`, checks for TMC4671 brownout reset (`readReg(0x0A) == 0` or cleared motor register) and forces full re-initialization via `uninitialized`.
  5. Restores power stage if `encoderAligned && motorEnabledRequested && canRunMotor()`.
- **Post-Power Recovery**: Sets `allowStateChange = true` and resumes `postPowerState` if not `NONE`; otherwise transitions to `requestedState` if `encoderAligned`.

---

### **State: `Running`**
- **Role**: Periodic fault, E-stop, and thermal supervision (`handleStateRunning()`).
- **Actions**: Every **200 ms**, runs `statusCheck()`, polls hardware `ENABLE_IN` via `checkHardwareEstop()` (when `motorEnabledRequested`), and reads thermistor temperature (`getTemp()` -> transitions to `OverTemp` if above `temp_limit`).
- **Real-Time Torque & Anti-Cogging**: Real-time torque/flux commands and 20-harmonic anti-cogging synthesis (with predictive phase-lead and asymptotic speed-ripple compensation) are executed directly in `TMC4671::turn()` when called by `Axis`, not in `handleStateRunning()`.

---

### **State: `Shutdown`**
- **Role**: Safe stopped state with power stage disabled.
- **Actions**: Ensures `disablePowerStage(true)` / `enablePin.reset()` is maintained. If `estopTriggered`, polls `isHardwareEnableHigh()` every 100 ms to clear `ESTOP_ERROR` and re-enter `uninitialized` once hardware enable is restored. Otherwise, if `!emergency && motorEnabledRequested && motor_type != NONE`, safely resumes via `startMotor()`.

---

### **States: `OverTemp` & `HardError`**
- **`OverTemp`**: Immediately invokes `enterHardError()`.
- **`HardError`**: Permanently keeps `DRV_ENABLE` low, `PWM_FOC` off, and torque zeroed (`enterHardError()` + `Delay(250)`). Cannot be exited without an MCU reset.

---

### **States: `EncoderInit`, `ExternalEncoderInit` & `EncoderFinished`**
- `EncoderInit` / `ExternalEncoderInit`: Run `encoderInit()` when powered and a motor type is configured.
- `EncoderFinished`: Marks `encoderAligned = true`. If `fullCalibrationInProgress`, saves encoder settings to Flash and chains directly into `SlewRateCalibration`; otherwise transitions to `Running` (if `motorEnabledRequested && isSetUp()`) or `Shutdown` (`stopMotor()`).

---

### **Calibration Routines**

#### **Full Calibration (`FullCalibration`)**
- Checks emergency, `brake_failure`, `MotorType::NONE`, and `hasPower()` (saving `postPowerState = FullCalibration` on power loss).
- Disables the flux biquad filter, enables the power stage safely via `enablePowerStageForCalibration(false)`, runs `calibrateAdcOffset(500)` + `saveAdcParams()`, then runs `calibrateEncoder()` (which transitions to `EncoderInit` / `ExternalEncoderInit` -> `EncoderFinished` -> `SlewRateCalibration`).

#### **Slew-Rate Calibration (`SlewRateCalibration`)**
- Runs `measureMaxSlewRate()` (3 ms flux step with `canRunMotor()` guard) and updates `maxSlewRate`. Transitions to `Running` or `Shutdown` (or `waitPower` with `postPowerState` if VM drops).

#### **Index Search (`IndexSearch`)**
- Runs `autohome()` with `allowStateChange = false`, then transitions safely to `Running` or `Shutdown`.

#### **Cogging Calibration (`CoggingCalibration`)**
- **Mechanism**: Delegated to `TMC4671CoggingCalibrator::run()` (`TMC4671_cogging.h` / `TMC4671_cogging.cpp`), which executes the 8-stage continuous multi-speed DFT-128 calibration pipeline paced by `TIM_TMC` or `TIM_CALIBRATION` with bounded 50 ms waits and immediate E-stop / `brake_failure` aborts. See `doc/cogging_analysis.md` for full mathematical and timing details.
- **Memory Management**: Temporary DFT accumulators (~3 KB) are allocated on the FreeRTOS heap only during calibration and freed unconditionally in `cleanup:`. The resulting 20-harmonic table occupies 240 bytes in Flash/RAM.

#### **PID Auto-Tune (`Pidautotune`)**
- **Mechanism**: `handleStatePidAutoTune()` executes two atomic synchronous `while` loops inside the TMC thread:
  1. **P-gain ramp**: Steps `tuneFluxP` with `Delay(50)` stabilization until `getActualFlux() > 0.75 * targetflux`.
  2. **I-gain overshoot detection**: Applies current pulses after 100 ms settling and runs a tight **50 ms peak-sampling loop** without the 10 ms `Run()` loop delay so fast current overshoot peaks (`TMC4671_ITUNE_CUTOFF`, default 4%) are captured accurately.
- **Safety & Recovery**: Always restores previous safe `curPids` on failure or interruption, checks `canRunMotor()` on every iteration, and saves `postPowerState = Pidautotune` if power is lost before starting.

---

## 5. Memory and Stack Vigilance

- **Stack Limit**: The TMC thread stack is configured to `TMC_THREAD_MEM = 1024` words (**4 KB**). The worst-case static stack call chain during cogging calibration is **1,016 bytes** (verified via `-fstack-usage`), leaving > 2.5 KB of margin for SPI/HAL/FreeRTOS calls.
- **Heap Allocation**: Temporary calibration buffers (~3 KB in `TMC4671CoggingCalibrator`) are allocated on the heap and freed unconditionally upon exit or abort.
- **Safety**: Always initialize local stack variables before `Flash_Read()` calls (e.g., `encofs`, `cogging`, `scale_flash`) so blank Flash never leaves uninitialized values.

---

## 6. FreeRTOS Safety and Critical Sections

There is a strict orchestration requirement for hardware initialization and ISR handling to avoid FreeRTOS crashes:

1. **No Blocking in Critical Sections**: Calls like `xSemaphoreTake` (used in SPI transfers), `vTaskDelay`, or task creation must **never** occur inside a `cpp_freertos::CriticalSection`.
2. **Driver Instantiation Pattern**: In `Axis::setDrvType()`, the `TMC4671` object is instantiated and pre-initialized (`setEncoder`, `setupDriver`, `setPowerLimit`) **outside** the critical section so its constructor and setup can safely use SPI/Semaphores.
3. **The Swap**: The critical section is used only for the atomic pointer swap (`this->drv.release()` / `this->drv.reset(drv_new)`) and updating `conf.drvtype` and `maxTorqueRateMS`.
4. **Deferred Cleanup**: Old driver objects are deleted **after** exiting the critical section so `~TMC4671()` (which stops timers, resets `extEncUpdater`, and disables the power stage) never runs with interrupts disabled.
5. **No Blocking SPI in ISRs**: `emergencyStop()` / `turn()` guard SPI access with `inIsr()`, and `FLAG_Pin` `exti()` latches `flagCheckPending` so `statusCheck()` executes safely in the TMC thread.

---

## 7. Interaction with User Commands

Calibration commands (`fullCalibration`, `calibrateCogging`, `pidautotune`, `findIndex`, `encalign`) are handled in `TMC4671::command()` (note: `cogging` only enables/disables runtime compensation):
1. **Pre-condition Guards**: Commands are rejected when `isEmergencyActive()`, `brake_failure`, `state == HardError`, `calibBusy` (`isCalibrationInProgress() && !allowStateChange`), `motor_type == NONE`, or (for powered `calibrateCogging`) `!encoderAligned || !adcCalibrated || enctype == NONE`.
2. **Request**: Valid commands call `changeState(...)` to schedule the target state (without directly modifying `allowStateChange`).
3. **Execution & Exit**: The state handler in `Run()` sets `allowStateChange = false` while running, executes the routine with continuous fault monitoring, restores `allowStateChange = true` upon completion, and transitions safely to `Running`, `Shutdown`, or `waitPower` depending on motor readiness and fault state.
